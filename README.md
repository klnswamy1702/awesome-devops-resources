## Kubernetes

### 1. [Kubernetes the Hard Way](https://github.com/kelseyhightower/kubernetes-the-hard-way)

**About:** A hands-on tutorial for bootstrapping a Kubernetes cluster
manually, without relying on scripts that hide the underlying steps. It
walks through core cluster components and helps explain how they fit
together.

**Learn:** TLS certificates, Kubernetes configuration, etcd,
control-plane components, worker nodes, networking, and cluster
troubleshooting.

**Best for:** Learners who already know basic Kubernetes concepts and
want a deeper understanding of cluster internals.

> This is a learning exercise, not a production-ready cluster deployment
> guide. Check the repository's current prerequisites and instructions
> before starting.

## DevOps Learning Roadmaps

### 2. [90DaysOfDevOps](https://github.com/MichaelCade/90DaysOfDevOps)

**About:** A structured, community-driven learning map covering DevOps
principles, processes, tools, and practical use cases. The material
includes topics across infrastructure, containers, automation, and
related operational practices.

**Learn:** Linux and DevOps fundamentals, containers, Kubernetes,
networking, infrastructure as code, automation, and DevSecOps.

**Best for:** Following a broad learning journey and building consistent
study habits through a guided collection of resources.

## Interview Practice

### 3. [DevOps Exercises](https://github.com/bregman-arie/devops-exercises)

**About:** A collection of DevOps interview questions, answers, and
exercises designed to help learners review concepts and prepare for
technical interviews.

**Learn:** Linux, networking, cloud platforms, Docker, Kubernetes,
Terraform, CI/CD, monitoring, and other DevOps topics.

**Best for:** Interview preparation, self-assessment, and identifying
gaps in your practical knowledge.

## Command-Line Skills

### 4. [The Art of Command Line](https://github.com/jlevy/the-art-of-command-line)

**About:** A practical guide to using the command line efficiently. It
collects useful shell commands, patterns, and techniques in a compact
reference that can be revisited while working.

**Learn:** Shell usage, text processing, file operations, command
composition, process management, and command-line productivity.

**Best for:** Developers, system administrators, and DevOps engineers
who want to become more effective in the terminal.

## System Design

### 5. [System Design Primer](https://github.com/donnemartin/system-design-primer)

**About:** A comprehensive learning resource for designing scalable and
reliable systems. It includes explanations of common system design
concepts, example architectures, interview questions, and study aids
such as flashcards.

**Learn:** Scalability, caching, load balancing, databases, sharding,
replication, queues, availability, and system design trade-offs.

**Best for:** Preparing for system design interviews and understanding
how large-scale services are architected.

## Suggested Learning Order

If you're building DevOps and SRE skills, follow this sequence:

1.  **The Art of Command Line** --- strengthen terminal and shell
    fundamentals.
2.  **90DaysOfDevOps** --- follow a broad, structured DevOps learning
    path.
3.  **DevOps Exercises** --- review concepts and practice explaining
    your answers.
4.  **Kubernetes the Hard Way** --- deepen your understanding of
    Kubernetes internals after learning the basics.
5.  **System Design Primer** --- learn to reason about scalable,
    reliable distributed systems.

## How to Use These Resources

-   Read actively and reproduce commands in a safe lab environment.
-   Keep your notes and practice solutions in your own repository.
-   Use interview questions to test understanding, not just memorize
    answers.
-   Check each upstream repository for its latest instructions, license,
    and maintenance status.
-   These descriptions are summaries; the linked repositories are the
    source of truth for their current contents.
